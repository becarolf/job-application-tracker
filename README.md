# Job Application Tracker 👩🏻‍💻

A full-stack job application tracker built to help me organize my own job search while practicing the skills I want to strengthen as I prepare for software development roles.

## Why I Am Building This

As I am currently preparing to enter the job market search in the software development field, I wanted to build something that solves a real problem in my own life: keeping track of job applications, interview stages, follow-ups, resume versions, and notes in one organized place.

Instead of building a generic CRUD app, I chose this project because it connects directly to my current career goals. It gives me the opportunity to practice full-stack development while creating something I can actually use during my job search.

This project is also part of my summer learning plan (created and managed by myself), where I am focusing on strengthening my skills in React, TypeScript, backend development, SQL, testing, Git, and deployment.

## Project Goal

The goal of this project is to build a practical and well-documented full-stack application that demonstrates real engineering skills, including database design, API development, validation, authentication, testing, and thoughtful product decisions.

## Planned Features

- User registration and login
- Add, edit, and delete job applications
- Track application status
- Save job posting URLs
- Store company, job title, salary, location, and notes
- Track the resume version used for each application
- Follow-up reminders
- Filter and sort applications
- Dashboard with application analytics
- Tests for core API flows

## Application Status Pipeline

Possible application statuses:

- Saved
- Applied
- Recruiter Screen
- Technical Interview
- Final Interview
- Offer
- Rejected
- Withdrawn
